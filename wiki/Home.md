# Archivyst

**Vectorless, Reasoning-Based RAG for Obsidian Vaults**

Archivyst is an intelligent archivist and analyst for your Obsidian vaults. It mimics how humans read documents — by navigating structure, not computing similarity scores. Instead of chunking your notes into vectors, it builds hierarchical Table of Contents trees and uses LLM reasoning to traverse them.

## Key Highlights

- **No vector database** — no Chroma, Pinecone, or embeddings to manage
- **Local LLMs** — runs entirely on your machine via LM Studio, Ollama, llama.cpp, or any OpenAI-compatible server
- **Cognitive memory** — learns across sessions with entity extraction, contradiction detection, and a full memory lifecycle
- **Code processing** — parse and document source code files (Python, C, SQL, etc.) into structured markdown
- **Obsidian-native** — works with wikilinks, backlinks, and vault structure
